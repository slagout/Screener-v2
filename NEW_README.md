# Francine Screener v2

This is the Francine Screener v2 application, a stock screening tool that uses institutional-grade methodologies to identify quality stocks in the S&P 500.

## Features

- Screens S&P 500 stocks using Francine's updated institutional methodology
- Filters by industry, geography, price range, options liquidity, implied volatility
- Displays qualified companies with detailed metrics
- Provides top picks for income strategies
- Web-based interface using Streamlit

## Requirements

- Python 3.8+
- Streamlit
- yfinance
- pandas
- numpy
- requests
- altair

## Installation

1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run the application: `streamlit run app.py`

## Usage

1. Open your browser to the URL displayed in the terminal
2. Set your screening parameters
3. Click "RUN FRANCINE SCREEN v2"
4. View results in the browser
